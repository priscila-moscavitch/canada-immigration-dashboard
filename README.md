# Canada Immigration Dashboard

This project is a Streamlit web application built to explore immigration trends to Canada.

The dataset contains country-level immigration data from 1980 to 2013, including region, continent, development category, and total immigration values.

## Features

- Interactive histogram
- Interactive scatter plot
- Country-level immigration exploration

## Tools Used

- Python
- Pandas
- Plotly Express
- Streamlit

## Project Motivation

This project combines my learning journey in data analytics with a topic that is personally and professionally meaningful to me: immigration to Canada.
