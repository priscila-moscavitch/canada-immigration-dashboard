# Canada Immigration Dashboard

This project is an interactive data dashboard built with Streamlit to explore immigration patterns to Canada from 1980 to 2013.

## Overview

The dataset contains country-level immigration data, including region, continent, development category, and total number of immigrants over time.

This project focuses on identifying patterns, trends, and differences across countries and regions.

## Why this project

As an immigrant living in Canada with a background in international and migration law, this topic is both personal and professional.

This project represents the intersection between my lived experience and my transition into data analytics.

## Features

- Interactive histogram to explore distribution of total immigration
- Scatter plot comparing immigration trends over time
- Bar chart highlighting top countries
- Sidebar filters for dynamic exploration

## Tools & Technologies

- Python  
- Pandas  
- Plotly Express  
- Streamlit
